Verb-Subject Colorizer

Spanish person-marker highlighter using Paco’s “almost-always endings”. Runs entirely in your browser.
yo = red
tú = blue
él/ella/Ud. = yellow
nosotros = purple
ellos/Uds. = green
yo = 3rd shared = orange
Rules: color only person markers; in voy/estoy color oy only; in he/has/ha/hemos/han color after silent h; never color a in “ir a” or -ando/-iendo.
